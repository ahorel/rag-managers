# MatchConsult — Functional Overview

**Product:** MatchConsult
**Owner:** Orange Business — ESN Sourcing team
**Version:** 2.5

---

## What is MatchConsult?

MatchConsult is an AI-powered consultant matching platform designed for ESN (IT services company)
sourcing teams. It bridges the gap between **client needs** and **available consultants** by
automatically reading a client's request in natural language and ranking the internal consultant
pool by relevance — in under 30 seconds.

Without MatchConsult, a sourcing manager receives a client email or job description, manually
reads through dozens of CVs, and relies on memory and intuition to identify the best matches.
MatchConsult automates this first-pass filtering and presents a ranked shortlist with an
explanation for each candidate.

| User | Role |

| **Sourcing manager** | Enters client needs, reviews the ranked shortlist, sends results |

## Core workflow

### Step 1 — Enter the client need

The sourcing manager pastes any free-text description of the need into the interface:
- A client email ("We are looking for a senior Java developer…")
- A formal job description
- A short informal note ("urgent need for an available SAP consultant in Paris")

There is no required format. The input can be 2 lines or 2 pages.

Optional filters can be applied before launching the search:
- **Domain** (finance, telecom, insurance, industry, mobility, innovation)
- **Location** (city)
- **Remote policy** (full remote / partial / on-site)
- **Languages** (French, English…)
- **Available only** (exclude consultants currently on assignment)

### Step 2 — AI structures the need

The AI reads the free text and extracts a structured job profile:
- Job title
- Contract type (staff augmentation / fixed-price / permanent)
- Duration
- Required technical skills
- Soft skills
- Client context
- Start date, location, remote policy, languages, business domain

This structured profile is displayed to the sourcing manager so they can verify that the AI
understood the need correctly.

### Step 3 — Semantic search across all CVs

The platform searches the entire CV pool simultaneously using semantic similarity — not keyword
matching. This means:
- A CV mentioning "Spring Framework" is found when searching for "Spring Boot"
- A CV written in French is correctly matched to a query written in English
- The search captures the overall expertise profile of a consultant, not just surface keywords

### Step 4 — Multi-criteria scoring

Each consultant is scored across several dimensions:

**Technical skills (up to 55%)** — combines semantic similarity (how close the CV is to the
need overall) with direct keyword matching (are the specific required technologies literally
present in the CV).

**Business domain (up to 25%)** — bonus for consultants who have already worked in the
requested sector (finance, telecom, etc.). Adjacent domains receive a partial bonus
(finance ↔ insurance, telecom ↔ innovation).

**Availability (up to 15%)** — consultants available immediately score highest. Those with
a known end date score proportionally. Those on long-term assignments score a minimum neutral
value so they remain visible for planning purposes.

**Location & remote (up to 5%)** — bonus if the consultant's location and remote preferences
match the mission requirements.

**Seniority (up to 5%)** — if the request specifies "senior", "expert", or "junior", consultants
whose years of experience match the requested level receive a bonus.

The final percentage is normalised against the maximum achievable score for the active criteria
of that specific query. A search without domain or location filter will show scores out of 75%
maximum, not artificially capped at 75% of 100%.

### Step 5 — Ranked results

The top 10 consultants are displayed in order of relevance. For each:
- **Name, title, seniority**
- **Score** (percentage with colour-coded bar)
- **Availability status** (available / pre-available / on assignment until…)
- **Location**
- **Matched skills** (skills from the offer found in the CV)
- **Missing skills** (skills from the offer not found in the CV)
- **AI-generated explanation** — one sentence explaining why this consultant fits the mission

### Step 6 — Send results by email

The sourcing manager can send the shortlist directly from the interface. The email contains:
- The structured job profile generated by the AI
- The ranked consultant list with scores and explanations
- Direct links to each CV

## Key capabilities

### Natural language input
No form to fill in. Any text describing a need is accepted — client email, Word document,
verbal note. The AI does the structuring work.

### Semantic understanding
The system understands synonyms, related technologies, and context. Searching for
"microservices architect" will surface consultants who worked on "distributed systems" or
"cloud-native applications" even if those exact words appear in the query.

### Multilingual
CVs in French and client needs in English (or vice versa) are matched correctly.
The embedding model covers 50+ languages.

### Transparent scoring
Every score is broken down into its components (skills, domain, availability, location,
seniority). The sourcing manager can see exactly why a consultant ranked higher or lower.

### Real availability data
Consultant status (available / pre-available / on assignment) and expected availability dates
are maintained in the system. The scoring automatically penalises consultants who are not
available, without hiding them entirely — they remain visible for pipeline planning.

### Instant shortlist
From input to ranked results in 20–30 seconds, covering the entire consultant pool
simultaneously. No manual CV reading required for the first pass.

---

## What MatchConsult does NOT do

- It does not make the final hiring decision — it surfaces candidates for human review.
- It does not access external job boards or candidate databases — it works exclusively on the
  internal CV pool loaded into the system.
- It does not update consultant CVs automatically — CVs are manually uploaded.
- It does not schedule interviews or manage the recruitment pipeline.

---

## Data handled

| Data type | Source | Privacy |
|---|---|---|
| Consultant CVs | Uploaded manually by the team | Personal data — stored locally, never sent to external APIs |
| Consultant metadata | Maintained in a JSON file | Internal data — availability, domains, contact |
| Client needs | Entered by the sourcing manager | Sent to the LLM API (Groq/Anthropic) for structuring |
| LLM explanations | Generated by the AI | Not stored permanently |

> **Important:** Consultant CV content is embedded locally using an on-premise model
> (sentence-transformers running on the server). CV text is **never sent to any external API**.
> Only the client need text (the search query) is sent to the LLM for structuring.

## Automated quality testing

The platform includes an automated test suite that runs a battery of 9 predefined scenarios
after each deployment and emails a report to the team. The scenarios cover:

- Simple technical searches ("senior Java developer")
- Complex multi-skill expressions (Java + Spring Boot + Maven + JUnit)
- Domain-specific searches (MOA project manager in finance)
- Availability filtering (intercontrat only)
- Multi-criteria filtering (domain + location + remote + language)
- Robustness (invalid input rejection)
- Result consistency (same query twice)

This ensures that any code change does not silently degrade matching quality.
